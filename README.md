# Калистеника

Android-приложение для похудения на собственном весе: 12-недельная программа (коврик, пляж, турник по желанию), анимации техники для каждого упражнения, плеер тренировки со счётчиком повторов, таймерами удержания и отдыха, голосовыми подсказками, контроль веса, привычки и питание.

## Установка

1. Откройте на телефоне раздел **Releases** этого репозитория и скачайте `Calisthenics.apk` из последней сборки.
2. Откройте файл. Android попросит разрешить установку из этого источника (браузера или «Файлов»), разрешите.
3. Нажмите «Установить».

Новые версии ставятся поверх старой.

## Устройство

- `app/src/main/java/.../data/Program.kt` — программа: 3 фазы по 4 недели, 4 тренировки в неделю, прогрессия объёма по неделям.
- `data/Exercises.kt` — упражнения: техника, ошибки, варианты полегче/посложнее, замены без инвентаря.
- `app/src/main/assets/moves.json` — анимации фигуры. Генерируются скриптом `tools/moves.py` (`python3 tools/moves.py --preview <папка>` рисует кадры для проверки).
- `ui/PlayerScreen.kt` — плеер тренировки.

## Сборка

Каждый пуш в `main` и в ветки `claude/**` собирает APK в GitHub Actions и публикует его в Releases. Локально: `./gradlew assembleRelease`.

Стек: Kotlin, Jetpack Compose, Material 3, kotlinx.serialization. Данные хранятся в JSON-файле на телефоне, интернет не нужен.
